--------------------------------------------------------------------------------
맨 위 제목
--------------------------------------------------------------------------------
API 및 필드


--------------------------------------------------------------------------------
1. 사용자 정보 등록
--------------------------------------------------------------------------------
- 신상정보 (이름, 생년월일, 성별 등)
- 건강정보 (뇌졸중 등 질환, 과거 병력, 약물 알레르기)
- 복약 관련 정보 (현재 복용 중인 약)
- 가족력


--------------------------------------------------------------------------------
2. FastAPI (업로드 / OCR / 심박)
--------------------------------------------------------------------------------
- fastAPI - 업로드 (이미지 id, 파일 이름)
- fastAPI - OCR (약이름, 복용량, 복용횟수)
- fastAPI (heart rate)
- fastAPI (유저id, 심박수, bpm)
- 기존 bpm / 복용후 bpm / 변화량 감지


--------------------------------------------------------------------------------
3. 외부 API
--------------------------------------------------------------------------------
[e약은요 API]
- 품목기초코드
- 제품명
- 성분
- 제조사
- 효능 효과
- 사용법
- 주의사항
- 보관법

[DurAPI]
- 병용금기
- 임부금기
- 특정연령금기
- 효능중복
- 상호작용


--------------------------------------------------------------------------------
4. 앱 실행 흐름 (가운데, 위에서 아래)
--------------------------------------------------------------------------------
1) 앱 실행
2) 로그인 / 회원가입
   → (사용자 정보 등록)
3) 홈
4) 처방전 촬영 / 입력
5) OCR (image -> text)
6) OCR 결과 확인 및 수정
   - No  → (재촬영/수정 분기)
   - Yes → 다음
7) 약물 정보 및 복약 안전 정보 조회
8) 검색 출력 (복약 방법, 부작용, 기존 약과 충돌 여부)
9) 주의사항
10) 복약 정보 제공
11) AI 약사에게 질문 (제미나이)
12) 추가 질문 (반복 가능)

[심박·복약 줄기]
13) 복약 전 polar 기준 심박 측정
    - 심박 측정 Yes / No
14) 약 복용 지도
15) 복약 후 polar 심박 측정
16) 기존값 대비 심박 변화 확인
    - 정상
    - 비정상 (이상 변화 감지)
      → 사용자에게 이상 변화 알림
      → 보호자 알림
17) 기록 저장
18) 홈으로 복귀


--------------------------------------------------------------------------------
5. UX/UI (필요한 화면)
--------------------------------------------------------------------------------
- ① 로그인 화면 / 회원가입 화면 필요
- ① 홈
- 처방전 등록 / 처방전 촬영
- 처방전 인식 결과
- 주의·금기 설명 / ⑥ AI 챗봇
- 심박 측정 모듈: 폴라 메인 화면 / 측정 화면 필요
- 변화 감지 화면 필요
- 기록 저장 안내(상세) 화면 필요


--------------------------------------------------------------------------------
6. 저장 데이터
--------------------------------------------------------------------------------
- 처방전/OCR
- 심박 데이터
- 복용 약품 정보
- 알림
