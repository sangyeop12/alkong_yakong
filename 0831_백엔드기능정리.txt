1. 한 줄

============================================================
2. OCR / 처방전 등록
============================================================

입구
  app/routes/prescription.py
  app/services/prescription_service.py

처리
  app/services/ocr/engine.py
    - 사진 → raw_text
    - PNG/JPEG/GIF/WEBP MIME 구분
    - timeout / auth / unavailable 오류 코드 구분

  app/services/ocr/parser.py
    - raw_text → 구조화 JSON
    - filter_to_source: 원문에 없는 약·일수·횟수는 버림

  app/services/ocr/pipeline.py
    - engine → parser 조립

등록 연결
  - name_matcher 로 이름 맞추기
  - retrieve_official 로 공식약 확정
    1) mfds_drug_permission.db (허가정보 미러)
    2) alkongyakong.db medicines
    3) e약은요 API
  - 없으면 422 (MOCK INSERT 없음)
  - warning_note 저장
  - 응답에 ocr_trace

임시 테스트
  simple_test_server.py → ocr/pipeline 호출
  (옛 analyze_prescription_image 제거)


============================================================
3. 약 이름 매칭 · 자동완성
============================================================

matching/name_matcher.py
  - exact → 띄어쓰기 정규화 → 제형/밀리그램 제거 → fuzzy
  - 0.90 이상만 자동 확정
  - 0.75~0.90 은 후보만 (자동 확정 안 함)

matching/chosung.py
  - 초성 변환 (ㅌㄹㄴ 등)

pharmacist/suggestions.py
  - GET /api/v1/drug-explain/suggestions
  - 허가DB·e약은요·오늘약·로컬약 후보
  - 어르신 대충 입력 힌트 (열나, 타이래, 깜빡, 같이먹 …)
  - 초성 입력 지원
  - 연관 FAQ 문구 조합 (선택 시)

pharmacist/spell.py
  - 질문에서 약 이름 후보만 추출 (확정은 matcher)


============================================================
4. 챗봇 (AI 약사)
============================================================

입구
  app/routes/drug_explain.py
  POST /api/v1/drug-explain/chat
  GET  /api/v1/drug-explain/suggestions
  GET  /api/v1/drug-explain/{medicine_code}

본선
  pharmacist/chat_pipeline.py
    spell → matcher → retrieve
    → FAQ면 DB/고정 안내 답
      (안 먹었을 때 / 같이 먹으면 / 이 약 설명 / 복용)
    → 아니면 generate → guard
    → 실패 시 공식 원문 발췌 fallback

  retrieve.py
    - 허가정보 DB 1순위 (+ 오타 fuzzy 보완)
    - 로컬 medicines
    - e약은요

  generate.py
    - 원문만으로 쉬운 말 생성
    - 문장 3개·길이 검사
    - 카드용 generate_card_from_source + guard

  guard.py
    - 원문과 안 겹치는 문장·숫자 거절

Flutter 연동 참고
  - 채팅에 일치율·근거 충족률 등 내부 trace 노출하지 않음
  - 상단 FAQ 칩(지금 먹을 약 등) 제거됨
  - 입력창 위 연관 검색어 목록은 유지


============================================================
5. 쉬운 약 이름 (괄호 분류)
============================================================

목적
  암로디핀 5mg (혈압 낮춤)
  타이레놀콜드 (콧물·코막힘·재채기)
  처럼 이름 옆에 쉬운 설명을 붙임

DB
  easy_category_map.db
    - 공식 표현 ↔ 쉬운 말 대응표
    - 예: 감기의 제증상, 콧물, 해열 → 증상 디테일

코드
  pharmacist/easy_category_db.py  표 DB
  pharmacist/easy_category.py     조회·표시 문자열
  medicines.easy_category         등록 시 저장 칸 (alkongyakong.db)

생성 시점
  OCR/공식약 upsert, 카드용 medicines upsert

원칙
  표·원문에 단서 없으면 괄호 억지로 안 붙임
